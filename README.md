# 一一与芽芽兽 · 3D 立体绘本馆 📖✨

> 岛主数字群岛生态 · 给女儿的一一成长绘本与原创 IP「芽芽兽」3D 互动立体绘本馆。

深度复刻 StoryComet 3D 精装纸张物理曲面网格翻页引擎，全静态 WebGL 渲染，真实纸质质感与光影，支持中文儿童伴读、逐词高亮与全景三维交互。

## 🌟 核心特色

1. **3D 精装纸张翻页引擎**
   - 原生 Three.js 物理曲面模拟，完美还原精装硬壳封面与内页翻动弧度与投射阴影。
   - 随光影流转的纸张纤维贴图与氛围粒子星空。

2. **完整收录 46 部绘本**
   - **一一成长绘本（36本）**：严格按照女儿出生成长月龄编年史（1-36）顺序排布，从《春天里最重要的事》（出生）、《爸爸的手掌心》（初抱）到《冲冲冲，一一玩水啦》。
   - **芽芽兽 IP 绘本（10本）**：原创角色芽芽兽的温馨奇幻冒险世界。

3. **双页画册式黄金排版（Plan A）**
   - 左侧温暖手绘场景图，右侧清晰排版故事正文与金句。
   - 自适应宽屏与触控交互，支持点读发音与背景氛围音。

4. **100% 纯静态部署**
   - 零后端依赖，极速响应，支持 GitHub Pages 全球 CDN 加速。
