# 一一与芽芽兽 · 3D 立体绘本馆 📖✨

> 岛主数字群岛生态 · 献给女儿一一的童年成长绘本与原创 IP「芽芽兽」3D 互动立体绘本馆。

深度学习并致敬 StoryComet 3D 精装纸张物理曲面网格翻页引擎，全静态 WebGL 渲染，真实纸质质感与光影，支持中文儿童伴读、逐词高亮与全景三维交互。

---

## 🪶 创作手记与缘起

这里是由 **岛主（一一爸爸）** 为女儿一一打造的童年故事馆。

从女儿一一出生至今，爸爸以她的日常点滴、童真奇想与相伴岁月为灵感，创作了一系列原创成长编年绘本与温暖的陪伴 IP 形象 **「芽芽兽」**。

在这个数字绘本馆里：
- **36 本一一成长绘本**：严格按照女儿出生成长月龄（从第 1 部《春天里最重要的事》到第 36 部）编年排列，记录一个小生命如何感知风、认识云、学会爱与探索世界。
- **10 本芽芽兽奇幻绘本**：用童真笔触构建奇妙自然的冒险篇章。

## 🙏 技术源泉与诚挚致敬 (Tribute & Credits)

本馆的核心 3D 纸张卷曲翻页物理引擎、精装书硬壳模拟与材质光影渲染，深度学习并致敬了由 **Meng To / DesignCode** 团队创作的杰出 WebGL 立体书工程 **[StoryComet](https://storycomet.app/)**。

## 🌟 核心特色

1. **3D 精装纸张物理翻页**
   - 基于 Three.js 物理曲面模拟，高度还原精装硬壳书脊、书页翻折弧度与柔和纸张阴影。
   - 随光影流转的纸质纤维质感贴图与氛围浮空星光粒子。

2. **完整收录 46 部原创绘本**
   - **一一成长绘本（36本）**：严格遵循时间线，记录初抱、满月、学步、涂鸦、夏日玩水等成长珍贵片段。
   - **芽芽兽 IP 绘本（10本）**：温暖生动的奇幻自然童话。

3. **双页画册黄金比例自适应**
   - 左侧温暖手绘场景图，右侧清晰排版故事正文与重点金句。
   - 智能适配桌面端宽屏与移动端触控，支持点读、逐词高亮与氛围背景音。

4. **100% 纯静态部署**
   - 零后端依赖，全球 CDN 毫秒级加载。
